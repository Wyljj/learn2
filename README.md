# 职学 岗位培训与学习评价

将单位培训资料转为可审核的题目，组织员工练习、错题复训，按真实答题记录形成培训统计。原项目名为“智学 AI”；本轮将浏览器演示改为带服务端账号与本地持久化的试用版本。

**当前阶段：已完成本轮开发优化，待实际试用和单位认定。** 软件测试不等于实际应用。申报准备稿与空白试用记录在 `output/申报材料/`；不得把演示、测试数据或尚未实现的效益填成实际成效。

## 启动

需要 Node.js 22 或以上版本，无需安装运行依赖。

Windows 双击 `启动职学.cmd`，或在项目目录运行：

```powershell
node server.mjs
```

浏览器打开 `http://127.0.0.1:4317`。首次设置培训管理员，随后在人员页面建立学员账号。默认无账号、无资料、无题目、无历史成绩。原演示账号和浏览器缓存不迁移。

不要直接双击 `public/index.html`，也不能仅使用 GitHub Pages 运行新版：新版需要 Node 服务处理账号、审核和判分。原单页保存在 `legacy/index.html`，仅作改造前参考。

## 使用流程

1. 管理员粘贴资料，或读取 UTF-8 的 TXT/Markdown 文本；PDF、Word 需先提取并人工核对正文，当前没有实现二进制文档解析。
2. 人工录题、批量导入 JSON，或使用已配置的 AI 服务生成草稿。每道题都需关联资料并填写原文中真实存在的连续依据片段。
3. 管理员核对题目、答案与依据后发布。AI 草稿不会自动发布。
4. 学员登录，选择已发布题目练习并提交。提交前接口不下发答案；服务端按题型判分。填空题完整规范化匹配，多个可接受答案需明确录入。
5. 提交后查看答案、解析和原文依据；可选择仍处于发布状态的错题再练习。
6. 查看真实练习记录和分题型统计。管理员可导出业务 JSON 和练习汇总 CSV，导出不含口令哈希或登录会话。

批量题目格式（此处仅说明结构，必须替换为本单位实际资料与题目，不作为预置数据）：

```json
[
  {
    "type": "single",
    "stem": "与所选资料相符的题干",
    "options": ["选项内容一", "选项内容二"],
    "answers": ["B"],
    "explanation": "经审核的解析",
    "sourceExcerpt": "从所选资料正文逐字复制的连续原文"
  }
]
```

题型为 `single`、`multi`、`truefalse`、`fill`。选择题答案是 A—F 字母数组；判断题选项固定为“正确、错误”，答案对应 A 或 B；填空题 `options: []`，`answers` 是可接受的完整答案数组。批量导入全部校验通过才写入。

## 可选 AI 配置

支持 OpenAI 兼容 Chat Completions 接口。`.env.example` 是变量说明，不会自动加载。以 PowerShell 为例，在启动服务的同一个终端设置：

```powershell
$env:AI_BASE_URL = 'https://你的服务地址/v1'
$env:AI_MODEL = '你的模型名称'
# 通过安全的环境配置方式注入 AI_API_KEY，避免将真实密钥写入脚本或命令历史。
node server.mjs
```

三个变量 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 都有值时才启用 AI。凭据只在服务端使用。AI 生成会将所选资料发送给配置的服务，应使用允许发送的资料。单份 AI 资料最多 20000 字，每次 1—10 题；服务或返回格式异常时明确报错，不生成通用示例题充数。原文匹配只能检查引用存在，不能证明题意和答案正确，仍需人工审核。

本轮验证覆盖隔离模拟服务的请求、草稿、引用校验及失败处理；**没有使用真实 AI 凭据完成在线效果验证**。

## 数据与运行边界

- 数据保存在 `data/training.json`，使用加盐 scrypt 口令哈希、服务端会话、角色校验、同源写入校验和原子文件写入。
- 单进程、本机试用定位；请勿让多个服务进程共用同一数据目录。数据增长或多机构使用前应迁移至合适数据库并开展专门验证。
- 默认只监听 `127.0.0.1`，本地 HTTP。正式联网前须配置 HTTPS、反向代理、备份及运行监控。公开使用还需要补充账户生命周期、运维和容量治理，当前不宣称已具备企业规模部署能力。
- 可用 `PORT` 改端口、`DATA_DIR` 指定数据目录。启用联网部署时，应由管理员配置 `HOST` 和准确的 `PUBLIC_ORIGIN`；HTTPS 来源会启用 Secure Cookie。
- 浏览器业务导出用于留存、分析，不是可直接导入的全量恢复备份。恢复需停服后复制原始 `training.json`；原始文件含账号哈希，应妥善保护。会话只存内存，重启后重新登录。
- 建议停服备份数据文件并验证恢复；备份、导出的培训个人信息应由单位按实际授权管理。

```powershell
node --test
npm run check
```

测试覆盖原文校验、精确判分、真实统计、角色与记录隔离、发布门禁、并发重复提交、原子导入、持久化、AI 错误及导出字段。浏览器验证另记在 `docs/verification.md`。

## 申报使用

本项目尚未实际使用，准备稿不能直接作为“已投入应用并取得明显成效”的证明。应先选择实际岗位资料，开展题目审核和真实试用，记录人工出题时间、题目准确性、参与人数及反馈，再由单位认定成果及效益，按申报通知准备正式材料。
